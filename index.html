A bit about me

I got into this by noticing something simple: a lot of great local businesses in Northfield and the wider Birmingham area still don't have a website — or have one that hasn't been touched in years. So I started building them proper ones myself, on spec, to show owners exactly what's possible.

Every project on this page is a real, working website I designed and coded by hand — HTML, CSS and JavaScript, no frameworks, no bloat, fast to load on a phone in a shop doorway. I write the copy to fit the actual business, not a generic template, and I test every link and button before I call anything finished.

If you run a business without a website — or with one that isn't pulling its weight — I'd like to build the next one.
