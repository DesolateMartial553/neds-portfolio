# Ned

**Live site: [https://desolatemartial553.github.io/neds-portfolio/](https://desolatemartial553.github.io/neds-portfolio/)**

The portfolio of **Ned**, a web designer and developer in Northfield, Birmingham, showing the eight sites built on spec for local businesses that had none.

- **Design:** Sunny studio
- **Built with:** plain HTML, CSS and JavaScript. No framework, no build step, self-hosted fonts and images.
- **Hosting:** GitHub Pages, served from the `main` branch.

To run it locally, open `index.html` in a browser, or serve the folder with `python3 -m http.server`.
